🎮 Cyber Quest: The Rogue AI

A text-based adventure game built with Python. Explore rooms, fight enemies, collect rewards, solve puzzles, and challenge the final boss!

✨ Features

- ⚔️ Turn-based combat
- 🎒 Inventory and upgrades
- 🗺️ Room exploration
- 🧩 Puzzle challenges
- 💾 Save and load progress

🛠️ Built With

Python 3, JSON, and the "random" module.
